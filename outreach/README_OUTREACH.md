# Pilar — Outreach Kit

Tous les messages prêts à envoyer pour trouver de la data réelle et des bêta users.

> Note: PILAR works on any industrial machine. The current outreach kit targets pump-heavy sectors (water, O&G, mining) because that is where the default model is validated. As PILAR expands to new machine types, add sector-specific variants for each.

## Ordre d'action recommandé

### Semaine 1 — Quick wins (30 min/jour)
- [ ] Poster les 3 LinkedIn posts (forums_communautes.md)
- [ ] Poster sur r/PLC et r/Manufacturing (Reddit)
- [ ] Poster sur Eng-Tips et Maintenance Talk
- [ ] Envoyer 10 DM LinkedIn (responsables maintenance FR)

### Semaine 2 — Volume
- [ ] 20 DM LinkedIn (anglophone — water/mining/O&G)
- [ ] Emails constructeurs : Sulzer, KSB, Xylem, Grundfos
- [ ] Contact 3 labos universitaires (INSA, TU Delft, KTH)

### Semaine 3-4 — Follow-up + secteurs spécifiques
- [ ] Relances (templates inclus dans chaque fichier)
- [ ] Emails chemical/process (BASF, Arkema, Solvay)
- [ ] Contacter équipes digitales constructeurs (KSB Guard, Sulzer Sense)
