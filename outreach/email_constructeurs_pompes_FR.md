## Email type — Partenariat data

```
Objet : Partenariat data — IA maintenance prédictive pompes centrifuges

Madame, Monsieur,

Je développe Pilar (trypilar.com), une plateforme SaaS B2B de maintenance prédictive
pour pompes centrifuges industrielles, basée sur des modèles IA (RandomForest +
Isolation Forest + SHAP + prévision de durée de vie résiduelle).

Le modèle actuel est entraîné sur le dataset UCI Hydraulic Systems et NASA C-MAPSS.
Pour le valider et l'améliorer sur des données réelles de terrain, je recherche un
partenariat data avec un acteur du secteur.

Ce que je propose :
→ Intégration gratuite de vos données (anonymisées) dans le pipeline d'entraînement
→ Partage des résultats d'analyse et des modèles entraînés
→ Co-développement possible d'une intégration native avec vos systèmes de monitoring
→ Mention de votre marque comme partenaire technologique

Ce que j'attends :
→ Accès à des séries temporelles de capteurs pompes (vibration, pression, débit,
   courant moteur, température) avec labels de pannes si disponibles
→ Volume minimum : 500 cycles ou 6 mois de données

Seriez-vous disponible pour un appel de 30 minutes la semaine prochaine ?

Cordialement,
[Votre nom]
trypilar.com
```
